# voice

Голосовая студия: анкета заказа как разговор. Клиент открывает `/p/<editKey>/voice`, в центре экрана нейро-сфера,
редактор задаёт вопросы голосом, клиент отвечает и перетаскивает фото. Ответы сохраняются в ту же анкету, что и формы.
После разговора (и предоплаты) заказ уходит в обычный конвейер: `projects.submitted → ai → layout`, и готовый макет
появляется на том же экране. Там же голосом или текстом заказываются правки.

```
браузер ──POST /api/voice/sessions {editKey, mode}──▶ voice ──▶ projects (заказ), catalog (анкета)
   │                                                    └──▶ ElevenLabs: токен разговора
   │◀── provider, conversationToken, dynamicVariables ──┘
   └── WebRTC с агентом ElevenLabs: он слушает, думает и говорит;
       его вызовы инструментов выполняются в браузере и сохраняют ответы через /api/projects
```

## Два режима

| `VOICE_PROVIDER` | Что происходит |
|---|---|
| `elevenlabs` | Живой разговор с агентом ElevenLabs Agents (распознавание, LLM, голос, перебивания — на их стороне). Нужны `ELEVENLABS_API_KEY` и `ELEVENLABS_AGENT_ID` |
| `browser` (по умолчанию) | Без ключей: сценарный интервьюер (`shared/contracts/src/interview-script.ts`) идёт по анкете по порядку, говорит и слушает сам браузер (Web Speech API), где распознавания нет — ответы текстом |

Если ElevenLabs недоступен или микрофон запрещён, страница сама переходит на `browser`: заказ не блокируется.

## Агент как код

`src/agent/definition.ts` — промпт, голос, модель и 9 клиентских инструментов; `src/agent/context.ts` — то, что агент
получает на один разговор через `{{переменные}}`: правила режима, анкета с путями полей и уже известные ответы
(интервью) или страницы и тексты макета (правки). В кабинете ElevenLabs руками ничего не правится:

```bash
cd services/voice
ELEVENLABS_API_KEY=… npm run provision                              # создаёт агента, печатает ELEVENLABS_AGENT_ID
ELEVENLABS_API_KEY=… ELEVENLABS_AGENT_ID=agent_… npm run provision  # обновляет после правок
npm run provision -- --print                                        # показать, что уйдёт в API
```

Необязательные переменные скрипта: `ELEVENLABS_VOICE_ID` (голос из вашей библиотеки), `VOICE_LLM` (модель агента,
по умолчанию `claude-haiku-5-5`: быстрая и аккуратная с инструментами).

## Инструменты агента

Имена и параметры — контракт `VOICE_TOOLS` (`shared/contracts/src/voice.ts`); выполняет их страница
(`frontend/src/features/voice-studio/session/tools.ts`) функциями из `shared/contracts/src/interview.ts`, которые
проверяют значения теми же правилами, что и формы. На ошибку агент получает текст, что не так, и исправляется сам.

| Инструмент | Что делает |
|---|---|
| `save_answer`, `append_answer` | Записать или дополнить ответ: текст, дата (в том числе «12 декабря 2026»), вариант по названию |
| `add_list_item`, `remove_list_item` | Запись в список: событие хронологии, факт, правило |
| `request_photos` | Открыть на экране окно загрузки для поля с фото |
| `get_status`, `finish_interview` | Что заполнено; завершить интервью (вернёт недостающее, если рано) |
| `show_page`, `request_changes` | Режим правок: пролистать макет, передать правки в редакцию |

## Запуск и проверка

```bash
npm run dev      # PORT, PROJECTS_URL, CATALOG_URL из .env; VOICE_PROVIDER=browser работает без ключей
npm test         # сессии с поддельными шлюзами, соответствие агента и контракта инструментов
```

Ключ ElevenLabs живёт только на сервере: браузер получает одноразовый токен разговора. Агент приватный
(`enable_auth`), разговор без токена не начать. Стоимость — минуты ElevenLabs Agents; интервью занимает 5–15 минут.
